### 依赖边清单（结构化，工具消费权威源）

| From | To | Type | 说明 |
| --- | --- | --- | --- |
| P2 | P1 | state | P1 所有写操作（注册/上线/停用/注销）的守卫依赖 P2 账户处于活跃态且存在有效会话；P2 为公共基础协议 |
| P2 | P3 | state | P3 所有写操作（域名 claim/映射创建与管理/端点管理/绑定/install secret 轮换）的守卫依赖 P2 账户处于活跃态且存在有效会话 |
| P1 | P3 | state | P3 映射入口复用 P1 管理的节点（server，S2+ 在线）与网卡入口（公网 IP 作为 entry_ip）；server 注销前置检查 P3 非删除态映射引用 |
| P2 | P4 | state | P4 全部管理操作（站点创建/上传签名/commit/停用/启用/删除/列表/详情/测试清理）的守卫依赖 P2 账户处于活跃态且存在有效会话（无 register 式机器面例外）；P2 为公共基础协议 |
| P3 | P4 | state | P4 站点域名绑定复用 P3 域名基质（domain_pool/user_domains）并共享 fqdn_registry 统一 FQDN 台账——同一 FQDN 只能属于映射或托管站点之一（互斥）；P4 解绑删台账释放 FQDN，P4 软删保留台账行不复用；P3 随机二级域名分配保留，P4 在迭代 24 移除随机分配不影响 P3 |
| P1 | P4 | state | P4 站点公开读 TLS 复用 P1 证书池导入仓库语义——站点域名（含通配 *.root）证书由管理员经 POST /v1/certs/import 导入登记；P4 不依赖 P1 节点/网卡（对象存储网关承载入口） |
