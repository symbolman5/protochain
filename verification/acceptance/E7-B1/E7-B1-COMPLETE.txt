4. v0.2 关键设计点
--------------------------------------------------------------------------------

4.1 B1-I1 修复：组合层 schemaVersion 模式区分
- 组合层 WebDataJson 顶层 `schemaVersion='1.1'` + `generatedAt`
- 单协议 WebDataJson 顶层 `schemaVersion='1.0'`（既有不变）
- web serve / 未来消费方按 schemaVersion 分支，避免组合层与单协议结构异构带来的踩坑

4.2 B1-I2 修复：宽松 YAML 解析
- 新增 `preprocessYamlProse`：把 PROSE_KEYS 白名单内的字段转 literal block scalar（`|`）后再 parseYaml
- PROSE_KEYS：`name` / `expression` / `checkMethod` / `description` / `rule` / `assumption` / `impactIfViolated` / `queryObservationInterfaceId` / `permissionBoundary` / `syncSemantics`
- 算法：
  - 单行值：用单引号包裹（处理 YAML 特殊字符）
  - 多行值（下一非空行缩进 > key 缩进）：转 literal block scalar（保留 inline + 续行 + 空行）
- 边界：
  - 枚举字段（complexity / dependencyType / direction / readOnly）严格 YAML 解析不动
  - PROSE_KEYS 增长需在 PR review 显式列出

4.3 B1-I3 修复：web-serve 模式感知 + 链接修正
- CLI `web-serve` 启动时读 `web/data.json` schemaVersion：
  - `1.0` → 单协议探针（既有 E7-I2 逻辑）
  - `1.1` → 组合层探针（`/`、`/protocols/`、`/cross-refs`、`/cross-diff`、`/protocols/<id>` × N）
- `--skip-probe` 传 `probePaths=[]` 空数组而非 undefined（startServe 内 `?? DEFAULT_PROBE_PATHS` 不会 fallback）
- 首页子协议链接 `[P1](protocols/P1)` 去掉尾斜杠（VitePress 产物为 .html，非 /index.html）
