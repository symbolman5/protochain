基线说明

  • P0 静态站点（VitePress）不受影响：停掉本服务后 P0 产物仍可独立托管
  • 在线编辑落权威源（scenarios / bindings），从不直接动 derived/ 产物；变化一律经机械命令（generate-cases / bind / verify）
  • 本服务进程 不读取 / 不持有 TOKEN/SECRET/PASSWORD/APIKEY 类环境变量（启动 scrub）；如需绑定鉴权头使用，走子进程隔离（filterEnvForChild）
  • 页面 / 接口响应 不含 authConfig.token / stateMap.secret 等敏感键（redactSensitiveFields 整键删除）
